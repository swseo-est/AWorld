# 샌드박스 기본 모듈 (`base.py`)

이 스크립트는 AWorld 프레임워크에서 모든 샌드박스 구현체가 따라야 하는 공통 인터페이스를 정의하는 추상 기본 클래스 `Sandbox`를 포함합니다. 샌드박스는 에이전트가 도구를 안전하게 실행할 수 있는 격리된 환경을 제공하는 핵심 보안 기능입니다.

## 주요 구성 요소

### `Sandbox` (추상 기본 클래스)

`Sandbox` 클래스는 샌드박스의 "계약"을 정의합니다. 실제 실행 로직을 포함하지 않고, 모든 구체적인 샌드박스(예: `LocalSandbox`, `KubernetesSandbox`)가 어떤 속성과 메서드를 가져야 하는지를 명시합니다.

-   **인터페이스 정의**: 이 클래스는 에이전트 코드가 샌드박스와 상호작용하는 방식을 통일합니다. 에이전트는 `Sandbox` 인터페이스에 맞춰 작성되므로, 실제 샌드박스 구현체가 로컬 프로세스이든 쿠버네티스 파드이든 상관없이 동일한 방식으로 상호작용할 수 있습니다. 이는 "구현이 아닌 인터페이스에 맞춰 프로그래밍한다"는 중요한 소프트웨어 설계 원칙을 잘 보여줍니다.

-   **주요 속성(Properties)**:
    -   `sandbox_id`: 샌드박스의 고유 ID.
    -   `status`: 샌드박스의 현재 상태 (`INIT`, `RUNNING` 등).
    -   `timeout`: 샌드박스 작업의 타임아웃 시간.
    -   `mcp_config`, `mcp_servers`: 샌드박스 내에서 실행될 MCP 도구 서버에 대한 설정.

-   **추상 메서드 (Abstract Methods)**:
    -   `mcpservers`: 샌드박스 내에서 MCP 도구 서버를 실행하는 `McpServers` 객체를 반환해야 합니다.
    -   `get_info()`: 샌드박스에 대한 정보를 반환합니다.
    -   `remove()`, `cleanup()`: 샌드박스 사용이 끝난 후 관련 리소스를 안전하게 제거하고 정리하기 위한 메서드입니다.

-   **초기화 (`__init__`)**:
    -   샌드박스 ID, 타임아웃, MCP 설정 등 모든 샌드박스 구현체에 공통적인 속성들을 초기화합니다.

요약하자면, `base.py`는 샌드박스 시스템의 청사진 역할을 합니다. 에이전트가 의존하는 안정적인 인터페이스를 제공하며, 실제 복잡한 실행 로직은 `implementations/` 디렉토리의 하위 클래스에 위임합니다. 이를 통해 프레임워크는 유연성과 확장성을 확보하게 됩니다.
