# 핵심 태스크 모듈 (`task.py`)

이 스크립트는 AWorld 프레임워크에서 작업의 단위와 그 실행 결과를 정의하는 핵심 데이터 구조를 포함합니다. `Task` 클래스는 에이전트가 수행해야 할 모든 정보를 캡슐화하고, `TaskResponse`는 그 최종 결과를 나타냅니다.

## 주요 구성 요소

### `Task` (데이터 클래스)

`Task`는 에이전트 또는 스웜이 수행해야 할 작업 단위를 나타내는 중앙 데이터 구조입니다. 실행에 필요한 모든 정보를 담고 있는 "작업 명세서"와 같습니다.

#### 주요 필드:
-   **`id`, `name`**: 태스크의 고유 식별자와 이름.
-   **`input`**: 태스크를 시작하기 위한 초기 입력 데이터.
-   **`agent` 또는 `swarm`**: 이 태스크를 수행할 단일 에이전트 또는 다중 에이전트 시스템(스웜)을 지정합니다.
-   **`tools`, `tool_names`**: 에이전트가 기본적으로 가진 도구 외에, 이 특정 태스크를 위해 전역적으로 사용할 수 있는 추가 도구를 정의합니다.
-   **`conf`**: 태스크 실행에 필요한 설정을 담는 `Config` 객체.
-   **`context`**: 태스크의 실행 상태를 추적하는 `Context` 객체에 대한 참조.
-   **`hooks`**: 실행 주기의 특정 지점(예: 시작, 종료)에 실행될 사용자 정의 함수 목록.
-   **부모-자식 관계**: `parent_task`, `is_sub_task` 필드를 통해 태스크를 하위 태스크로 나누는 계층적 구조를 지원합니다.
-   **`to_dict()` 메서드**: `parent_task`로 인한 무한 재귀를 피하면서 태스크 객체를 직렬화(serialization)하는 중요한 메서드입니다.

---

### `TaskResponse` (데이터 클래스)

`TaskResponse`는 태스크 실행이 완료된 후의 최종 결과를 표준화된 형식으로 담는 데이터 클래스입니다.

-   **`answer`**: 태스크의 최종 결과물 또는 답변.
-   **`status`**: 태스크의 최종 상태 (예: `success`, `failed`).
-   **`trajectory`**: 태스크를 수행하는 동안 에이전트가 거친 모든 단계(생각, 행동, 관찰)의 기록.
-   **`success`**: 성공 여부를 나타내는 불리언 값.

---

### `Runner` (추상 기본 클래스)

`Runner`는 태스크 실행기의 추상 기본 클래스입니다. 프레임워크의 실행 엔진(`runners` 모듈)은 이 클래스를 상속받아 구체적인 실행 로직을 구현합니다.

-   **실행 라이프사이클**: `run()` 메서드를 중심으로 `pre_run()` (사전 실행), `do_run()` (핵심 실행), `post_run()` (사후 실행)의 명확한 라이프사이클을 정의합니다.

`Task` 객체는 에이전트에게 "무엇을, 어떤 도구로, 어떤 맥락에서" 수행해야 하는지를 알려주는 역할을 합니다. 그러면 `Runner`가 이 `Task`를 받아 실행을 관리하고, 최종적으로 `TaskResponse`를 생성합니다.
