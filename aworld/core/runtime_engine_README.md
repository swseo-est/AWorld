# 핵심 런타임 엔진 모듈 (`runtime_engine.py`)

이 스크립트는 AWorld 프레임워크의 계산 실행 환경을 추상화하는 역할을 합니다. 에이전트의 논리를 조정하는 것이 아니라, 함수가 실행되는 기본 인프라(로컬 머신, 분산 클러스터 등)를 통일된 방식으로 다루는 저수준의 핵심 모듈입니다.

## 주요 구성 요소

### `RuntimeEngine` (추상 기본 클래스)

`RuntimeEngine`은 **계산 엔진(Computing Engine)**을 위한 추상 기본 클래스입니다. 다양한 백엔드 인프라에서 함수를 실행하기 위한 통일된 인터페이스를 제공하는 것을 목적으로 합니다.

-   **추상화 계층**: 이 클래스 덕분에 `runners`와 같은 상위 모듈은 코드가 실제로 *어디서* 실행되는지 알 필요 없이 비즈니스 로직에만 집중할 수 있습니다.
-   **핵심 메서드**:
    -   `_build_engine()`: 특정 런타임(Spark, Ray 등)을 초기화하고 생성합니다.
    -   `execute()`: 실행할 함수 리스트를 받아 해당 런타임 환경에서 실행합니다.

---

### `RuntimeEngine`의 구현체들

AWorld는 다양한 실행 환경을 지원하기 위해 `RuntimeEngine`의 여러 구체적인 구현체를 제공합니다.

1.  **`LocalRuntime`**
    -   기본 엔진으로, 로컬 머신에서 함수를 실행합니다.
    -   비동기 함수는 동일한 프로세스 내에서, 동기 함수는 병렬 실행을 위해 `ProcessPoolExecutor`를 사용하여 여러 프로세스에서 실행합니다.
    -   주로 로컬 테스트 및 개발에 사용됩니다.

2.  **`SparkRuntime`**
    -   Apache Spark 클러스터를 사용하여 함수를 분산 실행합니다.
    -   데이터 브로드캐스팅 및 함수를 Spark 작업으로 실행하는 로직을 처리합니다.
    -   대규모 데이터 처리 및 분산 계산에 사용됩니다.

3.  **`RayRuntime`**
    -   Ray 클러스터를 사용하여 함수를 분산 실행합니다.
    -   `ray.remote`를 활용하여 함수 호출을 클러스터에 분산시킵니다.

4.  **`K8sRuntime`**
    -   `LocalRuntime`의 별칭(alias)으로 보입니다. 이는 쿠버네티스 파드(Pod) 내에서 실행될 때, 해당 파드의 제약 조건 내에서 로컬로 실행되는 것과 유사한 모델을 사용함을 시사합니다.

---

### 런타임 등록 및 팩토리

-   **`RUNTIME` 딕셔너리 및 `register()` 함수**: "local", "spark", "ray"와 같은 이름으로 `RuntimeEngine` 인스턴스를 등록하고 조회할 수 있는 간단한 팩토리 메커니즘을 제공합니다. 이를 통해 설정 파일에서 런타임 엔진의 종류를 지정하는 것만으로 실행 환경을 쉽게 교체할 수 있습니다.

결론적으로, `runtime_engine.py`는 강력한 추상화 계층입니다. 개발자는 에이전트나 태스크 코드를 변경하지 않고도, 설정을 통해 로컬 머신에서 코드를 테스트하거나 대규모 Spark/Ray 클러스터에서 분산 실행할 수 있습니다. 이는 AWorld 프레임워크의 유연성과 확장성의 핵심적인 부분입니다.
