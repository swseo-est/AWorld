# AWorld 핵심 프레임워크 (`aworld`)

이 디렉토리는 핵심 AWorld 프레임워크의 소스 코드를 포함합니다. AI 에이전트 및 다중 에이전트 시스템을 생성, 설정, 실행 및 관찰하기 위한 모든 기본 빌딩 블록을 제공합니다.

## 디렉토리 구조 및 주요 모듈

아래는 프레임워크 내 주요 하위 디렉토리와 그 역할에 대한 설명입니다.

| 디렉토리                | 설명                                                                                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`agents/`**           | 구체적인 에이전트 구현을 정의합니다. 일반적인 `LLMAgent`뿐만 아니라 직렬, 병렬 등 다양한 실행 모델을 위한 특수 에이전트를 포함합니다.                                                               |
| **`cmd/`**              | 커맨드 라인 인터페이스(`aworld`) 및 웹 API/UI 서버의 시작 로직을 포함하는 애플리케이션 진입점을 포함합니다.                                                                                              |
| **`config/`**           | Pydantic 모델을 사용하여 유효성을 검사하며 프레임워크의 모든 설정을 관리합니다. 에이전트 설정, LLM 제공자 설정, 태스크 설정 등을 포함합니다.                                                              |
| **`core/`**             | 프레임워크의 심장부입니다. `Agent`, `Swarm`(다중 에이전트 그룹), `Task`, `Tool`, `Context` 등 모든 주요 개념에 대한 핵심 데이터 구조와 추상 기본 클래스를 정의합니다.                                        |
| **`memory/`**           | 에이전트를 위한 포괄적인 메모리 시스템을 구현합니다. 단기 및 장기 메모리, 다양한 임베딩 모델, 여러 벡터 데이터베이스 백엔드(예: Chroma, Milvus)를 지원합니다.                                              |
| **`models/`**           | OpenAI, Anthropic 등 특정 구현을 통해 다양한 대규모 언어 모델(LLM)과 상호 작용하기 위한 제공자 독립적인 인터페이스를 제공합니다.                                                                        |
| **`output/`**           | 실행 중 에이전트가 생성하는 출력을 관리합니다. 아티팩트(코드 파일, 이미지 등) 처리 및 UI 표시를 위한 데이터 구조화를 포함합니다.                                                                         |
| **`runners/`**          | 프레임워크의 실행 엔진입니다. Runner는 정의된 태스크와 에이전트를 받아 이벤트 처리, 도구 호출, 상태 관리를 포함한 전체 실행 루프를 관리합니다.                                                              |
| **`sandbox/`**          | 에이전트가 코드를 실행하거나 강력한 도구를 안전하게 사용할 수 있는 격리된 환경을 제공합니다. 로컬 실행 및 확장 가능한 쿠버네티스 기반 샌드박스 구현을 포함합니다.                                          |
| **`tools/`**            | 에이전트가 사용할 수 있는 도구를 생성하고 관리하기 위한 프레임워크를 포함합니다. 또한 도구 서버에 연결하기 위한 MCP(Multi-agent Communication Protocol) 클라이언트 측 구현도 포함합니다.                  |
| **`trace/`**            | 관찰 가능성 모듈입니다. OpenTelemetry를 사용하여 전체 프레임워크를 계측하여 디버깅 및 성능 분석을 위한 에이전트 행동의 상세한 분산 추적을 가능하게 합니다.                                                  |
| **`utils/`**            | 전체 프레임워크에서 사용되는 공통 유틸리티 함수 및 헬퍼 클래스 모음입니다.                                                                                                                           |
| **`mcp_client/`**       | 에이전트가 외부 도구 서버와 통신할 수 있도록 하는 MCP(Multi-agent Communication Protocol) 클라이언트입니다.                                                                                             |
| **`checkpoint/`**       | 에이전트 실행 상태를 저장하고 복원하는 기능을 처리합니다.                                                                                                                                              |
| **`evaluations/`**      | 다양한 벤치마크에서 에이전트의 성능을 평가하기 위한 코드입니다.                                                                                                                                        |
| **`events/`**           | 에이전트의 생명주기 동안 발생하는 이벤트를 관리하고 처리하는 시스템입니다.                                                                                                                               |
| **`logs/`**             | 로깅을 위한 설정 및 유틸리티입니다.                                                                                                                                                                  |
| **`metrics/`**          | Prometheus를 지원하는 메트릭을 수집하고 노출하는 모듈입니다.                                                                                                                                           |
| **`prompt/`**           | LLM에 보내는 프롬프트의 생성 및 템플릿 작성을 관리합니다.                                                                                                                                               |
| **`replay_buffer/`**    | 훈련에 필수적인 에이전트 경험을 저장하고 재생하는 시스템입니다.                                                                                                                                        |
| **`session/`**          | 대화의 지속성을 허용하는 사용자 세션을 관리합니다.                                                                                                                                                     |
| **`__main__.py`**       | `aworld` 커맨드 라인 도구의 주 진입점입니다.                                                                                                                                                           |
