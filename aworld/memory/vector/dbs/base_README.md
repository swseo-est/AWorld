# 벡터 데이터베이스 기본 모듈 (`base.py`)

이 스크립트는 AWorld 프레임워크 내에서 사용되는 모든 벡터 데이터베이스 구현체들이 반드시 따라야 하는 공통 인터페이스인 `VectorDB` 추상 기본 클래스를 정의합니다.

## 주요 구성 요소

### `VectorDB` (추상 기본 클래스)

`VectorDB` 클래스는 다양한 벡터 데이터베이스(예: Chroma, Milvus, Pinecone 등)와의 상호작용 방식을 추상화하는 역할을 합니다. 메모리 시스템의 다른 부분들은 특정 데이터베이스의 API를 직접 호출하는 대신, 이 `VectorDB` 인터페이스를 통해 상호작용합니다.

-   **"인터페이스에 맞춰 프로그래밍" 원칙**: 이 클래스는 프레임워크가 특정 벡터 데이터베이스 기술에 종속되지 않도록 하는 중요한 역할을 합니다. 개발자들은 이 `VectorDB` 인터페이스를 구현하는 새로운 클래스를 추가하는 것만으로, 프레임워크의 다른 코드를 수정하지 않고도 새로운 벡터 데이터베이스 지원을 쉽게 추가할 수 있습니다.

-   **표준화된 메서드**: 벡터 데이터베이스가 공통적으로 제공하는 CRUD(생성, 읽기, 업데이트, 삭제) 및 검색 기능을 표준화된 메서드로 정의합니다.
    -   **컬렉션 관리**: `has_collection`, `delete_collection`
    -   **데이터 조작**: `insert`, `upsert`, `delete`
    -   **데이터 검색**:
        -   `search`: 가장 핵심적인 메서드로, 쿼리 벡터와 가장 유사한 벡터들을 찾아 반환합니다(유사도 검색). 메타데이터 필터링도 지원합니다.
        -   `query`: 벡터 유사도가 아닌, 메타데이터 필터를 기반으로 데이터를 조회합니다.
        -   `get`: 특정 컬렉션의 모든 데이터를 가져옵니다.
    -   **유틸리티**: `reset` (데이터베이스 전체 초기화).

요약하자면, `base.py`는 메모리 시스템의 벡터 저장소 부분을 위한 명확한 "계약"을 정의합니다. 이를 통해 시스템의 나머지 부분은 기본 벡터 데이터베이스가 무엇인지 신경 쓸 필요 없이, 일관된 방식으로 의미 기반 검색 기능을 사용할 수 있습니다. 이는 프레임워크의 모듈성과 확장성을 높이는 좋은 설계 방식입니다.
