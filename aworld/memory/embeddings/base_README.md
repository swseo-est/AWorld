# 임베딩 기본 모듈 (`base.py`)

이 스크립트는 텍스트를 벡터로 변환하는 임베딩(Embedding) 모델과의 상호작용을 위한 핵심 인터페이스와 데이터 모델을 정의합니다. 이는 의미 기반 메모리 검색의 가장 기본적인 구성 요소입니다.

## 주요 구성 요소

### 데이터 모델 (Pydantic Models)

메모리 및 벡터 저장소 시스템 전반에서 사용되는 표준 데이터 구조를 정의합니다.

-   **`EmbeddingsMetadata`**: 하나의 임베딩 벡터에 연관된 메타데이터를 저장합니다. 어떤 에이전트, 태스크, 사용자에 속하는지를 기록하며, 이는 검색 결과를 필터링하는 데 매우 중요합니다.
-   **`EmbeddingsResult`**: 임베딩된 단일 문서(또는 텍스트 조각)를 나타냅니다. 원본 텍스트 내용(`content`), 변환된 벡터(`embedding`), 그리고 관련 메타데이터(`metadata`)를 포함합니다. 검색 결과로 반환될 때는 유사도 점수(`score`)도 포함될 수 있습니다.
-   **`EmbeddingsResults`**: `EmbeddingsResult` 객체들의 목록을 담는 컨테이너로, 검색 작업의 표준 반환 형식으로 사용됩니다.

---

### `Embeddings` (추상 기본 클래스)

모든 임베딩 모델 구현체가 따라야 하는 핵심 인터페이스를 정의합니다. 매우 단순하며 두 가지 메서드로 구성됩니다.

-   `embed_query(text)`: 텍스트 문자열을 입력받아 부동소수점 리스트(벡터)를 반환합니다.
-   `async_embed_query(text)`: 위 메서드의 비동기 버전입니다.

---

### `EmbeddingsBase`

`Embeddings`를 상속하며, 설정 객체를 받는 생성자를 추가한 간단한 기본 클래스입니다. 구체적인 임베딩 구현체들은 이 클래스를 상_속받게 됩니다.

---

### `EmbeddingFactory` (팩토리 클래스)

`VectorDBFactory`와 마찬가지로, 설정에 따라 적절한 임베딩 모델 구현체를 생성하는 팩토리입니다.

-   **`get_embedder` (정적 메서드)**: `EmbeddingsConfig` 설정 객체를 입력받습니다.
-   설정 안의 `provider` 이름(예: "openai", "ollama")을 확인하여, 해당하는 구현 클래스를 동적으로 임포트하고 인스턴스화하여 반환합니다.
-   이를 통해 시스템의 다른 부분들은 텍스트가 벡터로 변환되는 구체적인 방식(어떤 모델을 사용하는지 등)에 대해 알 필요 없이, 일관된 방식으로 임베딩 기능을 사용할 수 있습니다.

요약하자면, 이 파일은 임베딩 하위 시스템의 데이터 계약(Pydantic 모델들)과 기능적 계약(`Embeddings` 인터페이스)을 모두 확립합니다. 이는 프레임워크의 나머지 부분이 특정 임베딩 기술에 종속되지 않도록 하는 중요한 추상화 계층입니다.
