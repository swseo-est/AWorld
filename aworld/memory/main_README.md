# 메모리 시스템 핵심 모듈 (`main.py`)

이 스크립트는 AWorld 프레임워크의 정교한 메모리 시스템을 정의하고 관리하는 핵심 구성 요소들을 포함합니다. 에이전트가 정보를 기억하고, 요약하고, 검색하는 모든 기능의 중심이 되는 모듈입니다.

## 주요 구성 요소

### `MemoryFactory` (팩토리 클래스)

메모리 시스템을 생성하고 접근하기 위한 주된 진입점입니다.

-   **설정 기반 생성**: `from_config` 메서드를 통해 설정 객체(`MemoryConfig`)에 따라 다양한 종류의 메모리 시스템(예: `AworldMemory`, `Mem0Memory`)을 생성할 수 있습니다.
-   **싱글톤 인스턴스**: `MemoryFactory.instance()`를 통해 애플리케이션의 어느 곳에서든 쉽게 메모리 시스템의 단일 인스턴스에 접근할 수 있습니다.
-   **전역 초기화**: `init` 메서드를 통해 애플리케이션 시작 시 메모리 시스템을 전역적으로 설정할 수 있습니다.

---

### `Memory` (추상 기본 클래스)

모든 메모리 시스템이 구현해야 하는 핵심 인터페이스를 정의합니다.

-   **구성 요소**: 정교한 메모리 시스템의 세 가지 핵심 요소를 초기화합니다.
    1.  **LLM 인스턴스**: 대화 요약 등 지능적인 메모리 작업을 위해 사용됩니다.
    2.  **임베더(`Embedder`)**: 텍스트를 벡터 임베딩으로 변환하여 의미 기반 검색을 가능하게 합니다 (`EmbedderFactory` 사용).
    3.  **벡터 DB(`Vector DB`)**: 생성된 임베딩을 저장하고 검색합니다 (`VectorDBFactory` 사용).
-   **핵심 메서드**: 메모리 항목을 추가(`_add`), 검색(`search`), 요약(`async_gen_summary`)하는 등의 메서드를 정의합니다.

---

### `AworldMemory` (구체적인 구현체)

`Memory`의 기본 구현체로, 프레임워크의 핵심 메모리 로직을 담고 있습니다.

-   **메모리 추가 (`_add`)**: 메모리 항목을 `memory_store`에 저장할 뿐만 아니라, 텍스트를 임베딩으로 변환하여 `_vector_db`에도 저장합니다.
-   **자동 요약**: 특정 조건(대화 턴 수, 컨텍스트 길이 등)이 충족되면, LLM을 호출하여 대화 내용을 자동으로 요약하는 기능(`_summary_agent_task_memory`)을 갖추고 있습니다. 이는 LLM의 컨텍스트 제한을 초과하지 않고 장기적인 대화를 관리하는 데 매우 중요한 기능입니다.

---

### `InMemoryMemoryStore`

`MemoryStore`의 가장 간단한 기본 구현체로, 모든 메모리 항목을 파이썬 리스트에 저장합니다.

-   간단한 사용 사례나 테스트에 매우 유용합니다.
-   실제 운영 환경에서는 `db/` 디렉토리에 정의된 것과 같은 영구적인 저장소(예: PostgreSQL)로 교체될 수 있습니다.

---

### 프롬프트

이 파일에는 LLM에게 메모리 요약을 어떻게 수행할지 지시하는 상세한 프롬프트(`AWORLD_MEMORY_EXTRACT_NEW_SUMMARY` 등)가 문자열로 정의되어 있습니다. 이는 프레임워크의 세심한 구현 수준을 보여줍니다.

요약하자면, 이 모듈은 매우 유연하고 강력한 메모리 시스템을 제공합니다. 간단한 키-값 저장소(`MemoryStore`)와 정교한 벡터 검색 기능을 결합하고, LLM 기반의 지능적인 요약 및 장기 기억 추출 계층을 추가했습니다. `MemoryFactory`는 이 복잡한 시스템을 AWorld 프레임워크 전반에서 쉽게 설정하고 사용할 수 있도록 만들어 줍니다.
