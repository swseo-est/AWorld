# 태스크 실행기 모듈 (`task_runner.py`)

이 스크립트는 AWorld 프레임워크에서 `Task` 객체를 실행하는 역할을 하는 추상 기본 클래스 `TaskRunner`를 정의합니다. 이 클래스는 태스크 실행을 위한 준비 단계를 처리하고, 실제 실행 로직은 하위 클래스에서 구현하도록 위임합니다.

## 주요 구성 요소

### `TaskRunner` (추상 기본 클래스)

`TaskRunner`는 `core/task.py`에 정의된 `Runner`를 상속받으며, `Task` 객체를 실행하는 데 특화되어 있습니다. 이 클래스는 정적인 정의(Agent, Swarm, Task)와 동적인 실행 사이의 다리 역할을 합니다.

#### 주요 책임:

-   **초기화 (`__init__`)**:
    -   실행할 `Task` 객체를 입력으로 받습니다.
    -   핵심적인 초기화 작업을 수행합니다. 예를 들어, `Task`에 단일 `agent`만 지정된 경우, 이를 단일 노드를 가진 `Swarm`으로 감싸서 처리 로직을 통일합니다. 이는 실행기의 나머지 로직을 단순화시키는 중요한 설계입니다.

-   **사전 실행 (`pre_run`)**:
    -   본격적인 실행에 앞서 모든 준비 작업을 수행하는 비동기 메서드입니다.
    -   **컨텍스트 관리**: 메인 태스크와 서브 태스크를 구분하여 올바른 `Context`를 생성하고 설정합니다.
    -   **스웜 초기화**: `Swarm`의 `reset()` 메서드를 호출하여 에이전트 그래프를 구축하고 실행 준비를 마칩니다.
    -   **전역 도구 초기화**: 태스크에 전역적으로 정의된 도구들을 초기화합니다.
    -   **초기 관찰(Observation) 생성**: 첫 번째 에이전트에게 전달될 초기 `Observation` 객체를 생성합니다.

-   **사후 실행 (`post_run`)**:
    -   태스크 실행이 완료된 후 필요한 정리 작업을 수행하기 위한 훅(hook)입니다. 현재는 비어 있지만, 하위 클래스에서 확장할 수 있습니다.

-   **핵심 실행 (`do_run`)**:
    -   `TaskRunner`의 하위 클래스가 반드시 구현해야 하는 추상 메서드입니다.
    -   실제 태스크 실행의 핵심 로직, 즉 에이전트에게 관찰을 전달하고, 액션을 받고, 도구를 실행하는 등의 단계별 루프가 이곳에 구현됩니다.
    -   이 메서드가 추상 메서드라는 것은, 태스크를 실행하는 다양한 전략(예: 이벤트 기반, 호출 기반)이 별도의 하위 클래스로 존재함을 시사합니다. (예: `EventRunner`, `CallDrivenRunner`)

요약하자면, `TaskRunner`는 태스크 실행을 위한 환경, 컨텍스트, 초기 상태를 모두 설정한 후, 실제 단계별 실행 로직은 구체적인 하위 클래스에 위임하는, 잘 설계된 추상화 계층입니다.
